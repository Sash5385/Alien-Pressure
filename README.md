# Alien Pressure

Тактическая 3D-игра (XCOM + RimWorld, мрачный тон): отряд землян против пришельцев в тылу врага.
Стек: React + TypeScript + Vite + Three.js.

```bash
npm i && npm run dev
```

- `src/game/` — логика: бой (`combat`), ИИ (`ai`), миссия, кампания и сохранения (`campaign`), черты (`traits`)
- `src/render/` — Three.js-сцена; персонажи — glTF из `public/models/` (Quaternius, CC0), без файлов — примитивы
- `src/Camp.tsx`, `src/Mission.tsx`, `src/App.tsx` — экраны лагеря, миссии и меню

Есть: шанс попадания и укрытия, overwatch, патроны, ранения (кровь, перелом), мораль и паника, черты и биографии,
4 типа пришельцев, туман войны, случайные карты, цели миссий (зачистка / эвакуация / удержание), опыт и повышения, лагерь (лечение, найм, технологии), 3 уровня сложности, сохранение в localStorage.
ИИ пришельцев «знает» позиции бойцов (туман действует только на игрока).
