# Alien Pressure

Тактическая 3D-игра (XCOM + RimWorld, мрачный тон): отряд землян против пришельцев в тылу врага.
Стек: React + TypeScript + Vite + Three.js.

```bash
npm i && npm run dev
```

- `src/game/` — логика (состояние, миссия, поиск пути)
- `src/render/` — Three.js-сцена; `.glb` из `public/models/` позже заменят примитивы
- Сейчас: сетка 20×20, 4 бойца vs 6 пришельцев, укрытия, свободная камера, выбор и движение (2 AP, 5 клеток).
