# Alien Pressure

Тактическая 3D-игра (XCOM + RimWorld, мрачный тон): отряд землян против пришельцев в тылу врага.
Стек: React + TypeScript + Vite + Three.js.

```bash
npm i && npm run dev
```

- `src/game/` — логика: бой (`combat`), ИИ (`ai`), миссия, кампания и сохранения (`campaign`), черты (`traits`)
- `src/render/` — Three.js-сцена; персонажи — glTF из `public/models/` (Quaternius, CC0), без файлов — примитивы
- `src/Camp.tsx`, `src/Mission.tsx`, `src/App.tsx` — экраны лагеря, миссии и меню

Есть: шанс попадания и укрытия, overwatch, патроны, ранения (кровь, перелом), мораль и паника, черты и биографии,
4 типа пришельцев, туман войны, случайные карты в 3 локациях (руины, лес, берег реки: деревья, кусты, трава, вода), цели миссий (зачистка / эвакуация / удержание), опыт и повышения, лагерь (лечение, найм, технологии), 3 уровня сложности, сохранение в localStorage.
Цели миссий: зачистка, эвакуация, удержание, ликвидация командира, диверсия (маяки). Оружие (автомат, ПП, дробовик, снайперка) и броня (жилет, пластины, экзоскелет) открываются за трофеи.
Графика: bloom, мягкие тени, небо, адаптивное разрешение (переключатель «Графика»), плавная камера.
Классы бойцов (штурмовик: подавление, снайпер: прицельный выстрел, медик: лечение, сапёр: мины). ИИ пришельцев: патрулирование, тревога от выстрелов/вида, скрытая атака. Бочки (взрывы, цепная реакция), огонь на траве, мосты. Автосохранение миссии, повтор миссии при поражении, управление пальцами (долгое нажатие = ПКМ, кнопка «Поворот»).
Карта 44×44: холмы (высота → меткость/обзор), дома, камни, деревья; окопы (1 AP) — укрытие со всех сторон; миникарта (🗺).
Размер карты 44×44 или 64×64 (в лагере). Дома, мосты и деревья разрушаются/горят; пришельцы-стрелки окапываются и занимают высоту.
Управление: ЛКМ — выбрать/идти/цель, ПКМ — повернуть бойца (в режиме гранаты — отмена), СКМ — сдвиг камеры.
3 AP у всех, гранаты (радиус 1,9; бьют и по своим), инвентарь, перезарядка (2 запасных магазина на бойца), звук синтезируется на WebAudio (без файлов).
ИИ пришельцев «знает» позиции бойцов (туман действует только на игрока).
